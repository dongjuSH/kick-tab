# KickTab 일별 작업 내역

어느 날 어떤 작업을 했는지 찾기 위한 기록이다. 최신 날짜가 위에 온다.

**쓰는 법**
- 날짜 제목 아래에 그날의 작업을 한 줄씩 쓴다: `- **담당 채팅** 작업 이름 — 핵심 변경`.
- 필요하면 들여쓴 줄 1~3개로 사용자 결정·데이터 변경·외부 호출 같은 꼭 남길 사실만 덧붙인다.
- 파일별 변경은 커밋(`git log`, `git show`)에, 진행 상태와 남은 확인은 `guide.md` §3에, 파일 역할은 `file-feature-map.md`에 둔다. 여기에는 쓰지 않는다.
- 같은 날짜 제목은 한 번만 쓴다. 그날 제목이 이미 있으면 그 아래에 줄을 더한다(새 작업이 위).

예시:

```markdown
## 2026-11-27 (금)

- **04** 평가 작성란 정리 — 입력란 위 '평가 작성'과 '!'를 빼고 '경기당 1개'만 남김.
  - 결정: 마이페이지 평가 수정 폼은 그대로.
```
