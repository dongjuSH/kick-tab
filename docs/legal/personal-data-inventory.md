- 생년월일·성별·전화번호·신분증·주소는 수집하지 않는다(연령은 만 14세 이상 자가확인만).
- **IP 주소는 저장하지 않는다.** 의견·인증번호 발송·인증 확인·로그인 요청 제한에 서버 메모리에서만 쓰고(단일 서버, 최대 1일 창), DB·파일에 기록하지 않는다. 단, 배포 호스팅의 접속 로그 보관은 호스팅 설정에 따른다 [배포 시 확정: 배포 호스팅 업체·리전].
- 서버 오류 로그에는 예외 종류만 남기고 입력값·이메일·인증번호를 남기지 않는다(SMTP가 설정되지 않으면 메일을 보내지 않고 요청을 실패 처리하며 인증번호를 어디에도 기록하지 않는다).

## 2. 브라우저에 저장하는 항목

| 이름 | 종류 | 내용 | 유효 기간 | 목적 |
| --- | --- | --- | --- | --- |
| `kt_access` | 쿠키(필수, httpOnly, SameSite=Lax, 운영 Secure) | 회원 ID·세션 버전이 든 서명 토큰(JWT) | 토큰 15분, 쿠키 14일 | 로그인 상태 확인 |
| `kt_refresh` | 쿠키(필수, httpOnly, 경로 `/api/v1/auth`) | 임의 값(서버에는 해시만) | 14일 | 로그인 유지·자동 갱신 |
| `kt-fav-guest` | localStorage | 비회원 관심 팀 ID(최대 5개) | 사용자가 지울 때까지 | 비회원 관심 팀 |
| `kt-review-draft:<회원ID>:<경기ID>` | sessionStorage | 작성 중 평가 본문(그 회원에게만 복원) | 평가 등록·수정 취소, 직접 로그아웃 성공 시 삭제. 세션 만료로 끊긴 경우는 같은 회원이 다시 로그인할 때까지 보존(탭을 닫으면 삭제) | 세션 만료·로그인 복귀 시 입력 보존 |
| `kt-review-intent` | sessionStorage | 경기 ID | 탭을 닫을 때까지(사용 즉시 삭제) | 로그인 후 평가 위치 복귀 |
| `kt-feedback-draft` | sessionStorage | 보내기 전 의견 초안 | 탭을 닫을 때까지 | 의견 입력 보존 |

분석·광고 쿠키는 없다.

## 3. 회원 탈퇴 시 처리(P-03, `DELETE /api/v1/me`)

계정·필수 확인 기록·로그인 세션·관심 팀·경기 평가·반응·소셜 연결을 즉시 삭제하고, 같은 이메일의 인증번호 기록도 지운다. 의견은 본문을 남기고 회원 연결만 해제한다. 별도 비밀번호 입력 없이 유효한 로그인 세션으로 본인을 확인한다. 같은 이메일로 다시 가입하면 새 계정이며 이전 데이터는 복구되지 않는다.

## 5. 운영 단계별 메모 (2026-11-22)

- **1차 목표 — 서비스 배포:** 운영자는 개인(신동주), 문의·개인정보 담당 kicktab2026@gmail.com. 푸터는 `운영자 신동주 · 문의 kicktab2026@gmail.com`(프런트 `SITE_OPERATOR_NAME`·`SITE_OPERATOR_EMAIL`, 배포 환경에도 같은 값). 주소는 개인 주소라 넣지 않는다. 인증 메일 발송 계정과 문의 계정은 분리했다.
- **2차 목표 — 광고 배너:** 약관 제5조 4항(광고 게재·외부 광고 사이트 책임)은 미리 넣어 두었다. 광고를 붙일 때 다시 볼 것:
  - 광고 제공자(예: Google AdSense)가 쿠키·광고 식별자를 쓰면 처리방침 제9조(자동 수집 장치)에 광고 쿠키와 맞춤 광고 거부 방법을, 제6조(국외 이전)에 광고 제공자를 추가하고, 쿠키 동의 화면이 필요한지 확인한다. 이 목록 2장의 '분석·광고 쿠키 없음'도 고친다.
  - 광고 수익이 생기면 사업자 등록 대상인지 확인하고, 등록하면 푸터에 상호·대표자·사업자등록번호를 표시한다(지금 푸터 설정에는 대표·주소 항목만 있으므로 그때 항목을 추가).
  - 광고 영역은 경기 정보·TOP 5와 구분되게 '광고' 표시를 한다.
