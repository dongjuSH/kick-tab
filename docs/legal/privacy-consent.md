# [필수] 개인정보 수집·이용 동의 (가입 화면 문구 초안 · draft)

> **법률 검토본이 아닙니다. 공개 전 별도 검토를 권장합니다.** 가입 화면의 '[필수] 개인정보 수집·이용 동의' 옆 '보기'에서 보여 줄 문구입니다. 기록 항목 ID는 `privacy_collection`, 버전은 확정 전까지 `draft`입니다.

KickTab은 회원 가입과 서비스 제공을 위해 아래와 같이 개인정보를 수집·이용합니다.

| 수집 항목 | 수집·이용 목적 | 보유·이용 기간 |
| --- | --- | --- |
| 이메일 주소, 닉네임, 비밀번호 | 회원 식별, 이메일 인증, 로그인, 비밀번호 찾기, 경기 평가 작성자 표시 | 회원 탈퇴 시까지 |
| 서비스 이용약관·개인정보 수집·이용 동의와 만 14세 이상 확인 여부, 확인 시각, 문서 버전 | 동의 사실 확인, 만 14세 미만 가입 제한 | 회원 탈퇴 시까지 |
| 인증번호 발송·확인 기록 | 이메일 소유 확인, 반복 요청·입력 제한 | 유효기간: 인증번호 10분, 확인 결과 30분. 보관: 가입 완료 시 확인 결과는 즉시 삭제, 이메일·발송 시각 기록은 마지막 발송 후 30일 뒤 파기, 탈퇴 시 즉시 파기 |
| 로그인 기록(로그인 유지 정보) | 로그인 상태 유지 | 유효기간: 최대 14일(로그아웃·비밀번호 변경 시 즉시 무효). 보관: 만료·무효가 된 기록은 그로부터 30일 뒤 파기, 탈퇴 시 즉시 파기 |

- 비밀번호와 인증번호는 원문을 저장하지 않습니다.
- 관심 팀, 경기 평가, 반응은 회원이 직접 등록할 때만 저장되며 탈퇴 시 삭제됩니다.
- 회원 정보는 대한민국(서울) 리전의 데이터베이스(Supabase)에 보관하며, 인증 메일 발송(Google Gmail)을 위해 이메일 주소가 국외로 이전될 수 있습니다. 자세한 내용은 개인정보 처리방침 제6조를 확인해 주세요.

**동의를 거부할 권리와 불이익:** 이용자는 개인정보 수집·이용에 동의하지 않을 수 있습니다. 다만 위 항목은 회원 가입에 꼭 필요한 정보이므로, 동의하지 않으면 회원 가입을 할 수 없습니다. 경기 일정·결과·순위·뉴스 등 공개 기능은 가입 없이 계속 이용할 수 있습니다.
